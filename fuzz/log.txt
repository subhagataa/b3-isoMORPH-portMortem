Summary
=====================================================================
Four differential fuzz runs total, spanning both targets (reader,
expect) and two independent seeds (default RNG stream, and an explicit
--seed 42 re-run requested specifically to rule out the default seed's
RNG stream happening to avoid a divergence). 30,000 inputs per run,
120,000 inputs total across all four runs. Zero mismatches and zero
timeouts in every run. This is stronger evidence of behavioral
equivalence than a single run would be, since it rules out the
specific "got lucky with one seed" failure mode.

Historical note: an earlier draft of this log referenced "244
non-crash mismatches mentioned in DECISIONS.md" as something this
result "superseded." That reference was incorrect -- DECISIONS.md
contains no such entry, and no record of that figure or of what
triggered it exists anywhere in this repo. It has been removed rather
than carried forward. If reader-target mismatches were genuinely
observed at some earlier point in development, that finding is not
currently documented and should not be treated as resolved or as
having happened, absent an actual DECISIONS.md entry describing it.

Known gap: peak RSS was not measured for either binary in this
environment (`/usr/bin/time` is absent from the rustlang/rust:nightly-
bookworm build image used here). See bench/methodology.md, Status
section, for detail and the fix needed before that number can be
reported.
